THE FOOD RECIPE - FRONTEND PROJECT

HOW TO RUN
1. Extract this folder.
2. Keep index.html, item.html, script.js, style.css, admin.html, admin.js and admin.css in the same folder.
3. Open index.html in your browser (or use VS Code Live Server).

HOW IT WORKS
- index.html is the first page. Choose Admin or User.
- The selected role opens the existing login/sign-up modal on item.html.
- Admin login goes to admin.html.
- User login keeps the recipe website open.
- User/admin accounts are stored in the browser's localStorage.
